# Contributing to flutter_doctor_ai

Thank you for your interest in contributing! 🚀

## Setup

After cloning the repository, run:

```bash
dart pub get
```

## Code Style

- Please follow the Dart [Effective Dart](https://dart.dev/guides/language/effective-dart) guidelines.
- Run `dart format .` before submitting a PR.
- Fix all lints with `dart analyze`.

## Submitting Changes

1. Fork the repository and create your branch from `main`.
2. Make your changes.
3. Ensure your code is formatted and passes analysis.
4. Open a pull request with a clear description of your changes.

## Issues

If you find a bug or have a feature request, please open an issue on GitHub.
